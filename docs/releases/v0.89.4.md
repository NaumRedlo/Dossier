## Dossier 0.89.4 — пред-релиз

Первая сборка настольного приложения целиком: движок встроен, отдельно ставить ничего не нужно, кроме **ffmpeg**.

| | |
|---|---|
| `dossier-0.89.4-macos-arm64.zip` | Mac на Apple Silicon (M1 и новее) |
| `dossier-0.89.4-macos-x64.zip` | Mac на Intel |
| `dossier-0.89.4-windows-x64.zip` | Windows 10/11 |
| `dossier-0.89.4-linux-x64.tar.gz` | Linux |

ffmpeg: `brew install ffmpeg` · `winget install ffmpeg` · `sudo apt install ffmpeg` — или приложение скачает его само на первом запуске.

Сборка не подписана. На macOS в первый раз открой `Dossier.app` правым кликом → «Открыть» (или `xattr -dr com.apple.quarantine Dossier.app`); на Windows — «Подробнее» → «Выполнить в любом случае».

### Что внутри

- **Реплеи** — библиотека из osu!stable, lazer и своих папок и рендер одной кнопкой.
- **Видео** — все готовые рендеры в одном месте.
- **Сообщество** — досье (своё и любого участника группы), живая лента группы и новостей, люди, общий и адаптивный рейтинг, титулы; всё обновляется само.
- **Воркер** — в настройках: включи «Брать работу у бота», и приложение будет рисовать реплеи, которые участники ваших групп присылают боту, — 1080p, 60 кадров, выровненная громкость.
- Привязка к боту кодом на первом запуске: копировать токены не нужно.
