## Dossier 0.97.3 (pre-release)

This update fixes map information in the balance desk. Version 0.90.0 and newer can update automatically.

- Show the mod-adjusted star rating in the upper-right corner of the review card, with the original NM rating below it. When the server has no rating, Dossier calculates it in the background from the matching map file obtained through mirrors.
- Restore missing song titles, difficulty names and mapper information for maps added through links. Both mirror lookups now request the mapset information when the map response omits it.
- Queue rows show the difficulty name beneath the song title. Catalogue rows also use recovered names instead of numeric IDs.
- Display distinct `GRAVEYARD`, `WIP`, `PENDING`, `RANKED`, `APPROVED`, `QUALIFIED` and `LOVED` badges instead of grouping statuses under “Unranked”.

Map downloads are bounded and checked against the requested map ID and, when supplied by the server, file checksum. Calculated ratings are cached per revision; they do not change the server's catalogue admission decisions.

Witness remains disabled pending resolution of client-integration restrictions.
