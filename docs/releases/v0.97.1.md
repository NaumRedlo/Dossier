## Dossier 0.97.1 (pre-release)

This update fixes duel matchmaking and makes the balance desk easier to use. Version 0.90.0 and newer can update automatically.

### Duels

- Players searching from the app are now visible to matchmaking before a live duel connection is opened.
- The app restores the server's queue state and original waiting time. Repeating a search keeps the existing place instead of reporting that the player is already queued.
- A cancelled duel with an unavailable pool no longer leaves stale queue entries that interfere with later offers.
- Search and acceptance timers update every second without requiring mouse movement or another server response.

### Balance and Kamerton

- The desk checks for changes every two seconds while open, refreshing maps, labels, catalogue counts and model versions without reopening the tab. Selected maps and unfinished input are preserved.
- Reviewer presence appears in the relevant tabs and maps. Saved labels and confident assignments can be corrected or moved.
- Labelling accepts map batches, including batches without tournament slots. The sidebar lists reviewers' own batches; the separate OWC table has been removed.
- The queue supports star-range filtering and groups difficulties from the same mapset. Map details show clearer difficulty names, BPM, mod-adjusted values and compact slot badges.
- Map previews in Balance start from the Listen button. Import and other operations show progress and report failures.
- The workspace and its tabs are centered, catalogue panels fit their content, and the empty map-batch panel is larger and centered. The Back button has a compact size, vertical scrollbars are hidden, and scrolling inside columns no longer dims the application header.
- Shared controls use quieter dark surfaces, clearer selected states and the existing category colours.

### Verification

- 54 server tests cover duel state transitions, HTTP presence, matchmaking and repeated searches after cancellation.
- Seven application tests cover duel state and timers. GPU layout checks cover narrow and wide windows; all 26 balance reference screens were checked on hardware `wgpu` in Russian and English.
- Interface previews, reference images and card exports use hardware `wgpu`; software-rendered UI references are no longer used.

### Server update

Update and restart the bot alongside the application. The queue and live balance fixes require the matching server changes through commit `4802cc88` in the bot repository. Duels still require Bancho access and enough eligible maps in every required slot; this update does not bypass pool requirements.

Witness remains disabled pending resolution of client-integration restrictions.
