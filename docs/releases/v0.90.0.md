## Dossier 0.90.0 — пред-релиз

С этой версии Dossier **обновляется сам**: дальше скачивать архивы руками не нужно.

| | |
|---|---|
| `dossier-0.90.0-macos-arm64.zip` | Mac на Apple Silicon (M1 и новее) |
| `dossier-0.90.0-macos-x64.zip` | Mac на Intel |
| `dossier-0.90.0-windows-x64.zip` | Windows 10/11 |
| `dossier-0.90.0-linux-x64.zip` | Linux |
| `SHA256SUMS` | контрольные суммы архивов |

Сборка не подписана: на macOS в первый раз открой `Dossier.app` правым кликом → «Открыть», на Windows — «Подробнее» → «Выполнить в любом случае». Обновления, которые приложение ставит само, этого уже не спрашивают.

### Новое

- **Обновления.** При запуске и раз в шесть часов приложение проверяет релизы, включая пред-релизы. Что нашлось — в плитке «Сборки»; у слова «Настройки» загорается красная точка, а уведомление предложит обновиться. «Обновить» скачивает архив, сверяет его контрольную сумму, ставит новую версию на место старой и перезапускает приложение. Если в этот момент идёт рендер, задание воркера или скачивание, обновление подождёт.
- **Молча, пока тебя нет.** Переключатель «Обновляться молча, пока меня нет» скачивает обновление сразу. Ставится оно после получаса без касаний или при следующем запуске.
- **Иконка.** У приложения появилась своя иконка — полосатая красная «D», как в углу окна: у exe на Windows, в `Dossier.app` на macOS, у окна на Windows и Linux.
- **Воркер** теперь плитка в настройках приложения, а не отдельная вкладка. Его состояние видно и в меню аккаунта.
- **Журнал листается перетаскиванием:** цепляешь за кадры и тянешь, с инерцией. Простое нажатие по-прежнему выбирает реплей.

### Исправлено

- lazer больше не принимается за stable — ни папка установки, ни папка данных. Если выбрать папку установки lazer, приложение само перейдёт к его данным.
- Реплеи новых версий lazer распознаются, а реплеи из lazer помечаются как lazer.
- Пузырь при наведении на кадр в журнале теперь непрозрачный: кнопки под ним больше не просвечивают.
- Привязка к боту открыта всем, кто зарегистрирован в группе с ботом (работает после обновления бота на сервере).
