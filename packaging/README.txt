DOSSIER — РЕНДЕР-ВОРКЕР
=======================

Эта папка — всё, что нужно, чтобы твой компьютер рендерил реплеи для бота.
Ставить Rust, Python и git не надо: движок и программа уже собраны здесь.

Нужна одна посторонняя вещь — ffmpeg. Он кодирует видео.

    Windows:  winget install ffmpeg
    macOS:    brew install ffmpeg
    Linux:    sudo apt install ffmpeg


ЕСЛИ СИСТЕМА РУГАЕТСЯ, ЧТО ЭТО НЕИЗВЕСТНАЯ ПРОГРАММА

Так и есть: программа не подписана, потому что подпись — это платный
сертификат, а не признак безопасности. Исходники открыты, ссылка внизу.

    macOS — сначала снять карантин, иначе просто не запустится:

        xattr -dr com.apple.quarantine .

    (точка в конце — это «здесь», выполнять из распакованной папки)

    Windows — «Система Windows защитила ваш компьютер»:
    «Подробнее» → «Выполнить в любом случае».

    Linux — если пишет «Permission denied»:

        chmod +x dossier dossier-worker


ЗАПУСК

    Windows:   dossier-worker.exe
    Mac/Linux: ./dossier-worker

Больше ничего. Программа сама спросит адрес бота (он уже подставлен) и
токен, сама проверит их у бота и сама всё сохранит. Никаких файлов
создавать не надо.

Токен — длинная строка, её тебе дали. Никому её не показывай: она и есть
право работать на бота. Программа её на экран не выводит — только
отпечаток вроде «64 chars, e4a6da63», по которому можно сверить, та ли
это строка, не показывая её саму.

Если токен не тот, программа скажет об этом сразу, а не через три дня
молчания.


ЧТО ВНУТРИ

    1  начать работу
    2  проверить, всё ли готово
    3  сколько отдавать этой машины
    4  подключение — сервер и токен
    0  выход

Пункт 3 — это про твои мощности. Машина и так сама сбавляет обороты на
батарее, в жару и когда ты за клавиатурой; здесь ставится потолок поверх
её решений:

    вполсилы, когда я за компьютером
    не больше N ядер
    пауза — стоять и не брать задачи
    работать только в часы (например с 22 до 6)

Меняется на ходу: сохранил — подействовало через секунду, перезапускать
не надо.

Работа идёт, пока окно открыто. Свернул — идёт. Закрыл или выключил
компьютер — бот рендерит сам, просто медленнее. Ничего не ломается от
того, что ты ушёл.


ЧЕГО НЕ ДЕЛАТЬ

Не растаскивай папку. Движок ищет шрифт в assets/ рядом с собой, и без
него видео выйдет без счёта, точности и комбо — на вид готовое, а на
деле нет. Перемещай папку целиком.


ДЛЯ ТЕХ, КТО ЛЮБИТ КОМАНДНУЮ СТРОКУ

    --check        проверить и выйти
    --polite       вполсилы
    --threads 4    потолок по ядрам
    --once         взять одну задачу и остановиться
    --service      напечатать юнит для автозапуска

С любым из них меню не показывается. Настройки лежат в
~/.dossier/worker.env (на Windows — %USERPROFILE%\.dossier\worker.env)
обычными строками KEY=value, и править их руками по-прежнему можно.


ЕСЛИ ЧТО-ТО НЕ ТАК

Пункт 2 почти всегда говорит, что именно. Если он доволен, а работа не
идёт — напиши, и приложи то, что он вывел.
