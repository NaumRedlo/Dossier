# Эталонные кадры

Обычный прогон использует `tiny-skia` и сравнивает 146 кадров с сохранёнными PNG, включая скрытое главное меню, серию уведомлений, компактный видеоплеер, очередь рендеров, всех игроков сервера, сравнение игроков, раскрытую боковую панель, панель результата с таблицей и со шкалой, панель титула, полученного и ещё нет, список полученных видео, открытое полученное видео до и во время загрузки и окно выбора игроков для отправки:

```sh
DOSSIER_GOLDEN_REVIEW=/private/tmp/dossier-review cargo test --offline --manifest-path native/Cargo.toml --test golden
```

Текущие кадры записываются в отдельную папку. Отсутствующий, повреждённый или отличающийся эталон вызывает ошибку; тест никогда не создаёт и не обновляет эталоны. Ошибка содержит путь к текущему кадру. Без `DOSSIER_GOLDEN_REVIEW` используется временная папка с ID процесса.

Для просмотра изменённого интерфейса можно отдельно выгрузить галерею:

```sh
ICED_TEST_BACKEND=tiny-skia cargo run --offline --manifest-path native/Cargo.toml -- --gallery /private/tmp/dossier-review
```

Перед заменой эталонов просмотрите новые кадры и проверьте, что изменения соответствуют задаче. Затем явно перенесите одобренные PNG в эту папку, сохранив имена и суффикс рендерера. Экспорт сначала завершает PNG в отдельной временной папке и только потом заменяет файл назначения.

Все проверки интерфейса, включая эти кадры, по умолчанию рисуются через `tiny-skia`: так задано в `.cargo/config.toml` в корне репозитория, одинаково на любой машине и в CI. Явная переменная `ICED_TEST_BACKEND` главнее этой настройки. GPU-набор эталонов удалён 29 сентября 2026 года: CI его не проверял, и он устарел.
