# Закрытая проверка дуэлей

Генератор собирает девять рабочих слотов: NM1–NM4, HD2, HR2, DT1, DT2 и TB.
FM1–FM4 остаются разметкой каталога по правилам OWC: фримод с HD, HR или HD+HR,
без своего навыка, поэтому Kamerton на них не учится. Слотов EZ и FL в каталоге нет. Модель назначает
категории, а генератор подбирает карты из допущенного каталога с учётом
уровня игроков. Вручную подтверждённые карты допускаются без новой модели.

После обновления серверного репозитория можно проверить наполнение каталога
без создания матча и комнаты:

```sh
venv/bin/python -m scripts.duel_probe --first 5.5 --second 5.8 --human-only
```

Уровни в этой проверке синтетические и одинаковы для всех навыков каждого
игрока. Команда читает каталог, не записывает результаты и не обращается к
Bancho. Ответ содержит статус, выбранные карты и недостающие слоты. Она не
проверяет подключение IRC, открытие комнаты или фактические профили игроков.

Если пул не собирается, сначала проверить наличие допущенных ranked-карт,
назначений по каждому рабочему слоту и анализа с нужными модами. Для закрытого
теста предпочтительны карты, проверенные людьми; TB не выбирается из
неуверенных назначений. Пустой слот нельзя заменять произвольной картой
другой категории ради запуска.

Далее два тестера с привязанными osu!-аккаунтами создают нерейтинговое
приглашение через раздел «Дуэли». Проверяют принятие, сборку пула, получение
карт, драфт и комнату, затем результат и отмену матча. Доступность комнат
зависит от серверного координатора и подключения Bancho; локальные тесты
генератора не подтверждают их работу на VPS.

Пул собирается, только если в коридоре каждого слота есть не меньше пяти
разных допущенных карт. Карты, которые Kamerton назначил сам, и карты,
найденные им среди новых ranked, попадают в пул только в слотах, где его
уверенные ответы проверены не меньше 10 раз и верны не меньше чем на 90%.
После обновления сервера опубликованную версию нужно обучить заново и
опубликовать: старые отчёты не содержат счёта по слотам, и до этого играют
только карты, подтверждённые людьми. Какие слоты открыты, видно в колонке
«Автодопуск» на вкладке «Модель».

На 29 октября изменения интерфейса и сервера проверены локально. VPS
не обновлялся из этой задачи, реальный матч не запускался.
