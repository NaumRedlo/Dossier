## Dossier 0.98.1 – Pre-release №33

This update brings Dossier through VPN clients that work as the system proxy, makes answers from the server smaller and lets Kamerton learn from balance batches. Version 0.90.0 and newer can update automatically.

| Archive | Platform |
|---|---|
| `dossier-0.98.1-macos-arm64.zip` | Mac with Apple Silicon |
| `dossier-0.98.1-macos-x64.zip` | Mac with Intel |
| `dossier-0.98.1-windows-x64.zip` | Windows 10/11 |
| `dossier-0.98.1-linux-x64.zip` | Linux |
| `SHA256SUMS` | Checksums of the archives |

**Connection**
- Dossier uses the system proxy, so a VPN client working as one now carries Dossier as well as the browser. Before, the Community feed could fail to load behind such a VPN.
- Answers from the server come compressed, so the Community feed and the balance desk's lists load faster on a slow connection.

**Balance desk**
- Training Kamerton first downloads the maps of balance batches that are not on the server yet, so batches now take part in training. The training card shows this step with the number of maps downloaded.
- The dashed outline that shows another reviewer on the same map has one dash on every corner and evenly spaced dashes along each side.

**Replays and videos**
- Under ScoreV2, a slider on stable gets a 100 only when more than half of its parts were caught, the head included, as the game counts it.
