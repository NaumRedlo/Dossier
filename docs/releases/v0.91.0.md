## Dossier 0.91.0 — пред-релиз

Всё, что нашлось на первом тестировании под Windows. Если стоит 0.90.0, приложение обновится само: плитка «Сборки» или уведомление.

| | |
|---|---|
| `dossier-0.91.0-macos-arm64.zip` | Mac на Apple Silicon (M1 и новее) |
| `dossier-0.91.0-macos-x64.zip` | Mac на Intel |
| `dossier-0.91.0-windows-x64.zip` | Windows 10/11 |
| `dossier-0.91.0-linux-x64.zip` | Linux |
| `SHA256SUMS` | контрольные суммы архивов |

### Новое

- **Поиск в журнале** — по игроку, карте и модам. `+HDDT` ищет набор модов, `+NM` — игру без модов. Можно просто начать печатать на главном экране, Esc очищает поиск.
- **Живой журнал.** Приложение следит за папками реплеев и карт, за `scores.db` и `Data/r` у stable и за базой lazer. Новые реплеи появляются сами, с уведомлением и кнопкой «Открыть»; выбранный реплей при этом не сбивается.
- **Прогресс анализа.** Пока библиотека читается, видно, сколько карт и реплеев уже разобрано: большой Songs больше не выглядит зависанием.
- **Скоры из игры.** Из `scores.db` stable подтягиваются все локальные скоры, у которых есть реплей в `Data/r`. Тысячи игр читаются из одного файла, а не по одному.
- **Масштаб интерфейса** подстраивается под монитор: 100 % на 1080p, крупнее на больших экранах, мельче на маленьких, и пересчитывается при переносе окна на другой экран. В новой плитке «Интерфейс» его можно задать вручную, от 80 до 150 %.
- **Ограничение процессора** — ползунок «Процессор» в плитке «Рендер»: 25, 50, 75 или 100 % ядер для своих рендеров и для воркера.

### Исправлено

- Привязка к боту на первом запуске больше не отвечает «рендер тебе не открыт»: бот пускает всех, кто зарегистрирован в группе с ним. Работает после обновления бота на сервере.
