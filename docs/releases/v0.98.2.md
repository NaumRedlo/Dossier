## Dossier 0.98.2 – Pre-release №34

This update adds replay removal and batch selection, fixes the empty duel after a pool rating, reduces background work and brings buttons and screen transitions onto one motion system. Version 0.90.0 and newer can update automatically.

**Replay library**
- Delete local replay files to the trash, individually or in batches. Select with Cmd/Ctrl, Shift, a group card or Cmd/Ctrl+A. Confirmation shows the number of files and their size; files that could not be removed stay listed with the reason.
- Replays inside lazer's own storage are protected from removal. Exported files can be removed normally.
- Enter renders the selected replay. Player and time are shown separately on flat replay cards.

**Duels and connection**
- Rating a finished duel's pool no longer replaces the result with an empty duel or triggers a request with an empty duel ID.
- Malformed server answers produce an explicit error instead of a blank duel.
- Readiness is requested through Ready in the osu! room, where the server starts the round once both players are ready.
- A persistent event connection reports changes to the player's duels, the public duel list and online presence. Dossier refreshes on those events and polls less often while connected.
- Both the event connection and live duel connection now use the system proxy, including VPN clients configured as a proxy.

**Resources**
- Community images load when their page needs them instead of all at launch, allowing the image cache to evict older pictures. Balance queue rows use smaller covers.
- The renderer loads its CJK font when a matching character is first needed.
- Idle windows do less work: folder watching reports actual changes, empty map searches slow down, and presence requests stop while the event connection is active.
- Background replay scenes pause after the window has been unfocused for five seconds and resume on return.
- These changes reduce unnecessary work; they do not establish a new memory ceiling. The recorded hour-long run before the latest idle optimizations was stable across 20 rounds, with median memory around 940 MB.

**Interface**
- Buttons ease their hover and release states without growing or shrinking. Pages and Community sections cross-fade, and the leaving page no longer accepts clicks.
- Panels use dark glass without outlines; section entrances use a single fade.
- The duels home scales with a wide window, and the running/finished duel panel fits its contents instead of stretching through empty space.
- Catalogue cards fade into the slot panel at the list edges, and the slot reason field explains what to write.

**Maintenance**
- Image loading for the main screen is separated into its own module.
- Added server response fixtures for duel parsing and a repeatable memory soak scenario. Existing interaction and layout checks were aligned with the current batch selection and catalogue behavior.
