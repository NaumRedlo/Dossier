# Засчитывание титулов: проверка 18 октября 2026

## Исправлено

В серверном репозитории `1984`, в `utils/title_progress.py`, проверки WYSI,
джекпота (`magic7`), комбо 2000 и набора модов (`masks_5`) не читали `LocalScore`.
Теперь локальная история участвует в этих проверках. Результаты с помогающими
модами исключаются через `Play.counts`. Повторный импорт не увеличивает комбо
или число разных модов: берётся максимум и множество соответственно.

Проверки находятся в `tests/unit/test_local_scores.py`: комбинации 727, 1727,
7270 и 726, джекпот, комбо 2000, моды и исключение Relax.
Изменения ещё нужно установить на сервер. Уже сохранённые скоры будут учтены
при следующем пересчёте титулов; повторно загружать их для этого не требуется.

## Что проверить следующим

1. Привязка локальных скоров к владельцу. `native/src/history.rs::gather`
   читает всю `scores.db`, а `digest` не фильтрует `Replay.player`.
   Нужна сверка с osu!-аккаунтом, привязанным к токену, и отдельная обработка
   старых ников после переименования. Проверка: база с результатами двух игроков.
2. Пропущенные карты. Результат без записи в `osu!.db` пропускается,
   но отметка синхронизации может уйти вперёд. Нужна очередь повторной обработки,
   чтобы появление карты возвращало такой результат в синхронизацию.
3. Пересчёт после импорта. `/render/me/history` сохраняет скоры, но не запускает
   пересчёт титулов. Сейчас он зависит от полного обновления профиля или команды
   титулов. Нужна объединяемая очередь по игроку после импорта, с повтором при
   ошибке, чтобы не пересчитывать всю историю на каждый пакет из 500 скоров.
4. Источники данных для каждого правила. Локальная stable-база не различает
   Graveyard и Pending и не содержит даты ранкеда. Эти признаки следует получать
   из проверенных сведений о карте, а не угадывать. Серии попыток требуют
   хронологической истории с неудачными попытками и устранением дубликатов;
   список сохранённых успешных скоров не может её заменить.

Пока проверена конкретная причина WYSI и четыре перечисленных правила.
Это не подтверждение исправности всех титулов или чтения базы конкретного игрока.
