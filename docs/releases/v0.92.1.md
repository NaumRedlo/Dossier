### Исправлено

- **«Не вышло · a build from the source…»** больше не появляется. Если приложение перенесли, пока оно работало (например, из «Загрузок» в «Программы»), оно так и говорит и просит перезапуститься — после перезапуска «Обновить» работает.
- **Карантин macOS.** Если Dossier запущен прямо из «Загрузок» (macOS запускает такие приложения из временной копии только для чтения), приложение объясняет, что Dossier.app нужно перенести в «Программы».
- **Ошибки обновления** написаны по-человечески и переносятся по строкам, а не обрезаются.
