## Dossier 0.96.2 (pre-release)

Fixes for background activity in the tray, the idle replay scene and carousel navigation. Version 0.90.0 and newer can update automatically.

### Fixed

- Hidden and minimized windows no longer keep animated widgets active. Both live replay renderers suspend in the tray and resume when the window returns, preserving manual pause. Server presence and background export jobs remain available.
- Live render workers wait for frame requests instead of polling while inactive; stopping a worker wakes it immediately.
- The fullscreen idle scene starts whether inactivity is detected by the timer or an animation frame. It requests subsequent frames at about 30 FPS, while hidden carousel animations stop requesting redraws.
- Group backgrounds reach below the last replay with a small gap before the next group. Replay rows fill the width of their group's background.

### Changed

- Left and right arrows open the highlighted carousel group. Up and down move the highlight; Enter still opens the highlighted item.

### Verification

- Regression tests cover tray suspension and resumption, renderer waiting and shutdown, idle scene startup, carousel arrows and server presence in the tray.
- Windows CPU usage still needs comparison on testers' machines; no measured reduction is claimed for this release.

### Known limitations

- osu!mania maps converted from osu!standard do not yet have stars, PP or a rendered scene.
- Witness records osu!standard only. Witness Overlay is not visible in OpenGL fullscreen without compatibility mode.
