## Dossier 0.95.1 — pre-release

A small follow-up to 0.95.0 around the experimental Witness overlay. If version 0.90.0 or newer is installed, the app updates itself.

| Archive | Platform |
|---|---|
| `dossier-0.95.1-macos-arm64.zip` | Mac with Apple Silicon |
| `dossier-0.95.1-macos-x64.zip` | Mac with Intel |
| `dossier-0.95.1-windows-x64.zip` | Windows 10/11 |
| `dossier-0.95.1-linux-x64.zip` | Linux |
| `SHA256SUMS` | Checksums of the archives |

### Changed

- **The overlay hides itself when Witness loses the game.** If nothing has been read from the client for two seconds, or the client is closed or started again, the plates go away and a hold of the send key is dropped, instead of showing the last values.
- **Breaks follow the game's own timeline.** The end of the map is taken from the last object as the game plays it, so a long final slider with repeats no longer counts as a break.
- **Context for the overlay.** While the overlay switch is on, Dossier writes a small file with the interface language and the pool that holds the map being played; it is meant for the in-game overlay that is still in the works.

### For testers

- The repository now holds an experimental in-process overlay host for Windows in `tools/overlay-host`. It is not part of the archives and is not started by Dossier; its README says how to build and try it.

### Known

- Everything listed as known in 0.95.0 still stands: the overlay and the Alt+Tab fix have not been confirmed on Windows yet.
