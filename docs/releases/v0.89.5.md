## Dossier 0.89.5 — пред-релиз

Исправление первого запуска на Windows.

| | |
|---|---|
| `dossier-0.89.5-macos-arm64.zip` | Mac на Apple Silicon (M1 и новее) |
| `dossier-0.89.5-macos-x64.zip` | Mac на Intel |
| `dossier-0.89.5-windows-x64.zip` | Windows 10/11 |
| `dossier-0.89.5-linux-x64.tar.gz` | Linux |

### Что исправлено

- **Шаг «Папка osu!» больше не зависает.** Раньше поиск показывал результат, только когда досчитает всё, а подсчёт реплеев lazer открывал каждый файл его хранилища. На Windows это растягивалось на минуты, и экран стоял на «…». Теперь stable и lazer находятся сразу, а реплеи lazer досчитываются в фоне.
- Пока идёт поиск, можно вернуться назад или выбрать папку вручную.
- Хранилище lazer обходится в несколько потоков и запоминает проверенные файлы: повторно открываются только новые. Второй обход быстрее первого в десятки раз.
- Библиотека на Windows собирается заметно быстрее: папки карт считаются без лишнего обращения к диску на каждую запись, а новые карты разбираются параллельно.

Сборка не подписана: на macOS в первый раз открой `Dossier.app` правым кликом → «Открыть», на Windows — «Подробнее» → «Выполнить в любом случае».
