## Dossier 0.92.3 — хотфикс

Исправлены профиль, видеоплеер и оперативное меню после обновления 0.92.2.

| Архив | Платформа |
|---|---|
| `dossier-0.92.3-macos-arm64.zip` | Mac на Apple Silicon |
| `dossier-0.92.3-macos-x64.zip` | Mac на Intel |
| `dossier-0.92.3-windows-x64.zip` | Windows 10/11 |
| `dossier-0.92.3-linux-x64.zip` | Linux |
| `SHA256SUMS` | Контрольные суммы архивов |

### Исправлено

- Смена и снятие титула доступны только во вкладке «Титулы», в том числе при открытии собственного досье из списка людей или рейтинга.
- Плеер плавнее воспроизводит видео с высокой частотой кадров и синхронизирует изображение со звуком при ускорении до 2×.
- В оперативном меню убрано затемнение у верхнего края ленты.
- Профиль и постеры сохраняют читаемую ширину на больших экранах.
- Кнопка «Показать в папке» в Windows открывает каталог видео.
- Счётчики выполненных и возвращённых заданий воркера сохраняются после закрытия приложения.
