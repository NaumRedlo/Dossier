## Dossier 0.92.0 — пред-релиз

Всё из второго тестирования. Если стоит 0.90.0 или новее, приложение обновится само.

| | |
|---|---|
| `dossier-0.92.0-macos-arm64.zip` | Mac на Apple Silicon (M1 и новее) |
| `dossier-0.92.0-macos-x64.zip` | Mac на Intel |
| `dossier-0.92.0-windows-x64.zip` | Windows 10/11 |
| `dossier-0.92.0-linux-x64.zip` | Linux |
| `SHA256SUMS` | контрольные суммы архивов |

### Новое

- **Титулы меняются прямо в приложении:** «Надеть» и «Снять» в своём досье и на карточках в разделе «Титулы».
- **Лента по-настоящему живая.** Бот сам забирает свежие игры всех зарегистрированных, без `rs`. А когда приложение видит твой новый реплей, оно сообщает боту, и игра появляется в ленте через несколько секунд.
- **Журнал листает реплеи сам,** пока тебя нет. Отключается в плитке «Сцена».
- **При поиске кадры журнала плавно переезжают** на новые места.
- **Карту, которой нет ни на серверах, ни на зеркалах,** можно указать со своего диска: `.osz`, `.osu` вместе с папкой или `.zip`.
- **Переключатель «Только экспортированные реплеи»** в «Источниках» оставляет в журнале только реплеи из папок экспорта, без локальных скоров stable и хранилища lazer.

### Исправлено

- **Windows:** больше нет чёрного окна консоли — ни у приложения, ни у ffmpeg.
- **Ограничение процессора:** доля ядер теперь честно делится между отрисовкой и кодированием; раньше вместе они могли занимать вдвое больше. На Windows ограниченный ffmpeg работает с пониженным приоритетом.
- **Трейл курсора** больше не «плывёт» на высокой частоте кадров.
- **Нажатие курсора** плавно раздувает его, а не скачком.
- **Журнал с тысячами реплеев** больше не тормозит анимации: строятся только видимые кадры.
- **ffmpeg на macOS:** приложение, запущенное из Finder, теперь находит ffmpeg из Homebrew. Недокачанный собственный ffmpeg распознаётся и заменяется системным.
- **Фоны карт** находятся при любом регистре имени и слешах в пути. Если фон не указан, берётся самая крупная картинка из папки карты. Для карт, которых нет на диске, обложка и название берутся с зеркал.
- **Предустановленный новостной канал** больше не вытесняется более активными каналами.
- **Масштаб:** ползунок плавный, без делений, применяется при отпускании. Развёрнутое или полноэкранное окно он больше не сбрасывает в оконный режим.
- **Профиль:** постеры больше не растягиваются, точка «в сети» стала заметной, плашка серии — по ширине текста.
- **«Поискать на устройстве»** на Windows обходит все диски.
