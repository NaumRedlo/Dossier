# Эталонные кадры

Обычный прогон использует `tiny-skia` и сравнивает кадры с сохранёнными PNG, включая скрытое главное меню, серию уведомлений, компактный видеоплеер, очередь рендеров, всех игроков сервера, сравнение игроков, раскрытую боковую панель, панель результата с таблицей и со шкалой, панель результата, который пока видел только Witness, панель титула, полученного и ещё нет, список полученных видео, открытое полученное видео до и во время загрузки окно выбора игроков для отправки, источник «Реплеи игроков» в настройках, плитку Witness во время игры, аккаунт без Telegram и окно привязки Telegram:

```sh
DOSSIER_GOLDEN_REVIEW=/private/tmp/dossier-review cargo test --offline --manifest-path native/Cargo.toml --test golden
```

Текущие кадры записываются в отдельную папку. Отсутствующий, повреждённый или отличающийся эталон вызывает ошибку; тест никогда не создаёт и не обновляет эталоны. Ошибка содержит путь к текущему кадру. Без `DOSSIER_GOLDEN_REVIEW` используется временная папка с ID процесса.

Для просмотра изменённого интерфейса используйте GPU-предпросмотр (wgpu):

```sh
cargo run --offline --manifest-path native/Cargo.toml --example ui_preview -- main-prefs /private/tmp/dossier-gpu
```

Пример также принимает действия после пути: `scroll 500`, `drag 220 105 100 400`
или `scroll-drag 1200 250 240 70 500`. Координаты задаются в логических пикселях
окна 980×720; последний вариант сначала прокручивает страницу, затем переносит скин.

Перед заменой эталонов просмотрите новые кадры и проверьте, что изменения соответствуют задаче. Затем явно перенесите одобренные PNG в эту папку, сохранив имена и суффикс рендерера. Экспорт сначала завершает PNG в отдельной временной папке и только потом заменяет файл назначения.

Существующие эталонные тесты по умолчанию рисуются через `tiny-skia`: так задано в `.cargo/config.toml`, одинаково на любой машине и в CI. Это не бэкенд пользовательских предпросмотров: для них используется `ui_preview`, который принудительно выбирает `wgpu`. Явная переменная `ICED_TEST_BACKEND` главнее настройки Cargo. GPU-снимки нельзя сравнивать с эталонами tiny-skia; для них нужен отдельный одобренный набор PNG.
