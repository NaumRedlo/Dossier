## Рендер-воркер

Скачай архив для своей системы, распакуй **целиком**, и внутри — `README.txt`
с тремя шагами. Rust, Python и git не нужны: движок и программа уже собраны.

| | |
|---|---|
| `dossier-…-windows-x64.zip` | Windows 10/11 |
| `dossier-…-macos-arm64.zip` | Mac на Apple Silicon (M1 и новее) |
| `dossier-…-linux-x64.zip` | Linux |

Понадобится только **ffmpeg** — он кодирует видео:
`winget install ffmpeg` · `brew install ffmpeg` · `sudo apt install ffmpeg`

Дальше просто запусти `dossier-worker` — программа сама спросит адрес бота (он
уже подставлен) и код, сама всё проверит и сама сохранит. Никаких файлов
создавать не надо.

Код — восемь знаков вроде `K7M2-QPRS`, его выдаёт бот командой `cltoken`.
Живёт десять минут и годен на один компьютер. Длинные токены на 64 знака тоже
принимаются — у кого он уже есть, ничего перенастраивать не надо.

Внутри есть и настройки мощности: вполсилы, когда ты за компьютером; потолок по
ядрам; пауза; работать только ночью. Меняются на ходу, без перезапуска.

Программа не подписана — сертификат стоит денег и ничего не говорит о
безопасности, а исходники здесь же. Поэтому на macOS сначала
`xattr -dr com.apple.quarantine .` из распакованной папки, иначе система её не
запустит; на Windows — «Подробнее» → «Выполнить в любом случае». Подробнее в
`README.txt` внутри архива.

**Не растаскивай папку.** Движок берёт шрифт из `assets/` рядом с собой, и без
него видео выходит без счёта, точности и комбо — на вид готовое, а на деле нет.
