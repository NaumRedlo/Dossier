DOSSIER — РЕНДЕР-ВОРКЕР
=======================

Эта папка — всё, что нужно, чтобы твой компьютер рендерил реплеи для бота.
Ставить Rust, Python и git не надо: движок и программа уже собраны здесь.

Нужна одна посторонняя вещь — ffmpeg. Он кодирует видео.

    Windows:  winget install ffmpeg
    macOS:    brew install ffmpeg
    Linux:    sudo apt install ffmpeg


ШАГ 1. ВПИСАТЬ ТОКЕН

Создай файл с настройками. Windows — в Блокноте, «Сохранить как»,
имя в кавычках: "%USERPROFILE%\.dossier\worker.env"
Mac и Linux — ~/.dossier/worker.env

Внутри две строки:

    RENDER_SERVER=https://onenineeightfour.ignorelist.com
    RENDER_WORKER_TOKEN=<токен, который тебе дали>

Токен — длинная строка. Никому её не показывай: она и есть право
работать на бота.


ЕСЛИ СИСТЕМА РУГАЕТСЯ, ЧТО ЭТО НЕИЗВЕСТНАЯ ПРОГРАММА

Так и есть: программа не подписана, потому что подпись — это платный
сертификат, а не признак безопасности. Исходники открыты, ссылка внизу.

    macOS — сначала снять карантин, иначе просто не запустится:

        xattr -dr com.apple.quarantine .

    (точка в конце — это «здесь», выполнять из распакованной папки)

    Windows — «Система Windows защитила ваш компьютер»:
    «Подробнее» → «Выполнить в любом случае».

    Linux — если пишет «Permission denied»:

        chmod +x dossier dossier-worker


ШАГ 2. ПРОВЕРИТЬ

Запусти отсюда же:

    Windows:  dossier-worker.exe --check
    Mac/Linux: ./dossier-worker --check

Он ответит списком. Всё, что помечено [+], в порядке; [!] — то, что надо
починить, и рядом написано как. Задачу он при этом не берёт, так что
проверять можно сколько угодно.


ШАГ 3. ЗАПУСТИТЬ

    Windows:  dossier-worker.exe
    Mac/Linux: ./dossier-worker

Всё. Окно можно свернуть. Пока оно открыто — компьютер берёт задачи;
закрыл или выключил — бот рендерит сам, просто медленнее. Ничего не
ломается от того, что ты ушёл.


ЕСЛИ НАДО ПРИТОРМОЗИТЬ

При запуске:

    --polite       работать вполсилы, когда ты за компьютером
    --threads 4    жёсткий потолок по ядрам

Но лучше вписать в тот же worker.env — он перечитывается на каждом опросе,
так что менять можно на ходу и ничего не перезапускать:

    RENDER_POLITE=1        вполсилы
    RENDER_THREADS=4       не больше четырёх ядер
    RENDER_PAUSE=1         пауза: стоит и ждёт, задач не берёт
    RENDER_HOURS=22-6      работать только ночью, с 22 до 6

Сохранил файл — подействовало через секунду.


ЧЕГО НЕ ДЕЛАТЬ

Не растаскивай папку. Движок ищет шрифт в assets/ рядом с собой, и без
него видео выйдет без счёта, точности и комбо — на вид готовое, а на
деле нет. Перемещай папку целиком.


ЕСЛИ ЧТО-ТО НЕ ТАК

--check почти всегда говорит, что именно. Если он доволен, а работа не
идёт — напиши, и приложи то, что он вывел.
